# 📊 Superstore Sales Analysis & Dashboard

Welcome to the **Superstore Sales Analysis** project! This project demonstrates an end-to-end data analysis workflow, turning raw transactional sales data into meaningful business insights and interactive dashboards.

---

## 📌 Project Overview
The objective of this project is to analyze the performance of a retail superstore across different categories, customer segments, and geographical regions. By identifying trends and key drivers of revenue, this analysis provides actionable recommendations to optimize sales strategies.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel**: Data cleaning, Pivot Tables, Conditional Formatting, and Dynamic Dashboard Creation.
* **Python (Pandas & Seaborn)**: Exploratory Data Analysis (EDA) and data consistency checks.
