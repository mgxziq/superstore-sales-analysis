# 📊 Superstore Sales Analysis & Interactive Excel Dashboard

Welcome to the **Superstore Sales Analysis** project! This project demonstrates an end-to-end data analysis workflow performed entirely in **Microsoft Excel**, turning raw transactional sales data into meaningful business insights and an interactive dashboard.

---

## 📌 Project Overview
The objective of this project is to analyze the performance of a retail superstore across different categories, customer segments, and geographical regions. By identifying trends and key drivers of revenue, this analysis provides actionable recommendations to optimize sales strategies and business decisions.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel**:
  * Data Cleaning & Formatting (handling duplicates, missing values, and data types)
  * Data Analysis using **Pivot Tables** & **Pivot Charts**
  * Advanced Excel Formulas
  * Dynamic & Interactive **Sales Dashboard** with Slicers
